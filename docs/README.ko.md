# free mobile ai

![free-mobile-ai](../logo/wordmark.svg)

**집에 있는 컴퓨터를 주머니에서. 한 줄 명령으로, 앱 없이.**

> 밖에서도 집 PC가 풀파워로 작동. 포트 포워딩도, 공개 IP도, 모바일 앱도 필요 없음 — 브라우저에서 URL 열기만 하면 됩니다.

---

##这是什么?

**free mobile ai**는 제로 인스톨 터널-아즈-서비스입니다. 집 컴퓨터에서 **한 줄 명령**을 실행하면, Cloudflare 터널을 통해 모든 스마트폰/브라우저에서 접근할 수 있습니다. 포트 포워딩, 라우터 설정, 폰 앱 설치 모두 불필요합니다.

기본 사용 예는 **DeepSeek Harness (DSH) Web GUI**입니다: 전용 URL 하나로 폰에서 집 PC의 전체 AI 도구 체인(DeepSeek Harness / Codex / OpenClaw)을 조작할 수 있습니다. 그러나 **모든 로컬 HTTP 서비스**(홈 서버, 셀프호스트 앱, 개발 환경 등)를 노출할 수 있습니다.

### 설계 원칙 (v1.0)

| # | 속성 | 의미 |
|---|------|------|
| (a) | **제로 인스톨** (사용자측) | `curl \| bash` 한 줄. 그게 전부입니다. |
| (b) | **제로 앱** (소비측) | 폰은 브라우저로 URL을 열기만 하면 됩니다. App Store 불필요. |
| (c) | **제로 트래픽 저장** (플랫폼측) | 컨트롤 플레인은 당신의 데이터를 조회/복호화/저장하지 않습니다. |
| (d) | **회수 가능한 자격 증명** | URL = 열쇠. URL 로테이션 = 즉시 접근 회수. |
| (e) | **코드리스 인증** | 머신 코드 = 아이덴티티. 원타임 코드 불필요. |

## 퀵 스타트 (3단계)

### 1. 집 컴퓨터에서 인스톨러 실행

```sh
# macOS / Linux
curl -fsSL https://dsh.newapi.email/mai/i.sh | bash

# Windows PowerShell
irm https://dsh.newapi.email/mai/i.ps1 | iex
```

스크립트는 `cloudflared`를 다운로드(SHA-256 검증)하고 브라우저에서 로컬 콘솔을 엽니다.

### 2. 활성화 (한 클릭)

로컬 콘솔에서:
- **서비스 주소**: `127.0.0.1:3080` (기본 = DSH Web GUI). 임의의 `host:port`로 변경 가능.
- **"터널 시작"** 클릭.

머신 코드는 자동 감지됩니다. 인증 코드 불필요 — 머신이 곧 아이덴티티입니다.

### 3. 폰에서 전용 URL 열기

`https://x7k2m9.newapi.email` 형태의 전용 URL이 표시됩니다. 폰 브라우저에서 열기만 하면 끝입니다.

## 기능 (v1.0)

| 기능 | ID | 설명 |
|------|-----|------|
| 코드리스 자동 인증 | **L1** | machine code = identity. 멱등 활성화, 원타임 코드 불필요. |
| 로컬 멀티플렉서 | **L2** | 한 터널로 여러 도구 (`/t/<name>` 또는 `?tool=<name>`). 추가 터널 불필요. |
| 온라인 시간 추적 | **T1** | 30s 하트비트, 누적 온라인 시간, 라이프사이클 인식. |
| 도구 프리셋 + admin UX | **T2** | 바인딩별 도구 등록, admin측 실시간 가시화. |
| 별칭 (A1) | **A1** | 바인딩의 친숙한 이름. |
| 추천 귀속 (X9) | **X9** | 활성화 시 선택적 `ref` 파라미터; admin stats Top N 집계. |

## 아키텍처 (한 줄로)

```
폰 브라우저 ──HTTPS──▶ Cloudflare Edge (TLS 종료 + 포워딩만)
                              │
                    ┌─────────▼────────┐
                    │ 당신의 PC (상주)  │ ← cloudflared 아웃바운드, 공개 IP 불필요
                    ├──────────────────┤
                    │ mux :5380        │   /t/<name> → 127.0.0.1:<port>
                    │ DSH :3080        │   기본 도구
                    └──────────────────┘
```

- **컨트롤 플레인** (Node.js + SQLite): 머신 코드 등록, 바인딩 관리, 하트비트 생존 확인, 온라인 시간 추적. **업무 트래픽을 프록시하지 않습니다**.
- **데이터 플레인** (당신의 PC): cloudflared + 로컬 mux. Cloudflare 엣지는 TLS 종료와 바이트 포워딩만 수행합니다.

완전한 설계 및 보안 분석: [docs/paper.md](paper.md)

## 보안 모델 (능력 기반)

- **URL-as-credential**: 랜덤 서브도메인 URL = 접근 자격 증명. 높은 엔트로피, 추측 불가.
- **로테이션 = 회수**: URL 로테이션 → 구 URL 즉시 무효 (DNS/ingress 변경). 세션 토큰 회수 불필요.
- **머신 바인딩**: 단말기 1대 정책 (승인된 PC 1대). 다른 머신 → 하트비트 회수.
- **제로 저장**: 컨트롤 플레인은 바인딩 메타데이터만 저장 (머신 코드, 서브도메인, 상태). 요청/응답 본문은 저장하지 않습니다.

완전한 논문: [docs/paper.md](paper.md) (중국어) · [docs/paper-en.md](paper-en.md) (English)

## 환경 요구사항

| 구성요소 | 요구사항 |
|----------|----------|
| 집 컴퓨터 | macOS / Linux / Windows, **Node.js ≥ 18** (i.sh 자동 설치) |
| 폰 / 소비 기기 | 모던 브라우저 (Safari, Chrome, Edge). 앱 불필요. |
| 네트워크 | 아웃바운드 HTTPS (443)만 필요. 인바운드 포트·포트 포워딩 불필요. |
| Cloudflare 계정 | 무료 플랜으로 충분 (tunnel + DNS). 컨트롤 플레인이 API를 통해 터널 자동 생성. |
