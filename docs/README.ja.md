# free mobile ai

![free-mobile-ai](../logo/wordmark.svg)

**外出先から自宅PCを操作。1コマンドで、アプリ不要。**

> 外出中でも、家のPCがフル稼働。ポートフォワーディングもパブリックIPもモバイルアプリも不要——ブラウザでURLを開くだけ。

---

## これは何か？

**free mobile ai** は、ゼロインストールのトンネル・アス・サービスです。自宅PCで **1つのコマンド** を実行すると、Cloudflare トンネル経由でどのスマートフォンやブラウザからもアクセス可能になります。ポートフォワーディングも、ルーター設定も、スマホへのアプリインストールも不要です。

デフォルトのユースケースは **DeepSeek Harness（DSH）Web GUI** です：1つの専用URLで、スマホから自宅PCの全AIツールチェーン（DeepSeek Harness / Codex / OpenClaw）を操作できます。ただし、**任意のローカルHTTPサービス**（ホームサーバー、セルフホストアプリ、開発環境など）も公開できます。

### 設計原則（v1.0）

| # | プロパティ | あなたにとっての意味 |
|---|-----------|---------------------|
| (a) | **ゼロインストール**（ユーザー側） | `curl \| bash` 1コマンド。それだけ。 |
| (b) | **ゼロアプリ**（消費者側） | スマホはブラウザでURLを開くだけ。App Store不要。 |
| (c) | **ゼロトラフィック保持**（プラットフォーム側） | 制御面はあなたのデータを閲覧・復号・保存しません。 |
| (d) | **失効可能な認証情報** | URL = キー。URLローテーション = アクセス即時失効。 |
| (e) | **コードレス認証** | マシンコード = アイデンティティ。ワンタイムコード不要。 |

## クイックスタート（3ステップ）

### 1. 自宅PCでインストーラーを実行

```sh
# macOS / Linux
curl -fsSL https://dsh.newapi.email/mai/i.sh | bash

# Windows PowerShell
irm https://dsh.newapi.email/mai/i.ps1 | iex
```

スクリプトは `cloudflared` をダウンロード（SHA-256 検証）し、ブラウザでローカルコンソールを開きます。

### 2. アクティベーション（1クリック）

ローカルコンソールで：
- **サービスアドレス**：`127.0.0.1:3080`（デフォルト = DSH Web GUI）。任意の `host:port` に変更可能。
- **「トンネル開始」** をクリック。

マシンコードは自動検出されます。認証コード不要——マシンがアイデンティティです。

### 3. スマホで専用URLを開く

`https://x7k2m9.newapi.email` のような専用URLが表示されます。スマホのブラウザで開くだけで完了です。

## 機能（v1.0）

| 機能 | ID | 説明 |
|------|-----|------|
| コードレス自動認証 | **L1** | machine code = identity。冪等アクティベーション、ワンタイムコード不要。 |
| ローカルマルチプレクサー | **L2** | 1つのトンネルで複数ツール（`/t/<name>` or `?tool=<name>`）。追加トンネル不要。 |
| オンライン時間追跡 | **T1** | 30秒ハートビート、累計オンライン時間、ライフサイクル認識。 |
| ツールプリセット + admin UX | **T2** | バインディングごとにツール登録、admin側でリアルタイム可視化。 |
| エイリアス | **A1** | バインディングのフレンドリー名。 |
| 紹介帰属 | **X9** | アクティベーション時に任意の `ref` パラメータ；admin stats で Top N 集計。 |

## アーキテクチャ（一行で）

```
スマホブラウザ ──HTTPS──▶ Cloudflare Edge（TLS終端 + 転送のみ）
                              │
                    ┌─────────▼────────┐
                    │ あなたのPC（常駐）│ ← cloudflared 送信接続、パブリックIP不要
                    ├──────────────────┤
                    │ mux :5380        │   /t/<name> → 127.0.0.1:<port>
                    │ DSH :3080        │   デフォルトツール
                    └──────────────────┘
```

- **制御面**（Node.js + SQLite）：マシンコード登録、バインディング管理、ハートビート死活監視、オンライン時間追跡。**業務トラフィックをプロキシしません**。
- **データ面**（あなたのPC）：cloudflared + ローカル mux。Cloudflare エッジはTLS終端とバイト転送のみ。

完全な設計とセキュリティ分析：[docs/paper.md](paper.md)

## セキュリティモデル（キャパビリティベース）

- **URL-as-credential**：ランダムサブドメイン URL = アクセス認証情報。高エントロピー、推測不能。
- **ローテーション = 失効**：URLローテーション → 旧URLは即時無効（DNS/ingress変更）。セッショントークンの失効不要。
- **マシンバインディング**：単一端末ポリシー（1台の承認PC）。異なるマシン → ハートビート失効。
- **ゼロ保持**：制御面はバインディングメタデータのみ保存（マシンコード、サブドメイン、ステータス）。リクエスト/レスポンスボディは保存しません。

完全な論文：[docs/paper.md](paper.md)（日本語版は準備中）

## 環境要件

| コンポーネント | 要件 |
|---------------|------|
| 自宅PC | macOS / Linux / Windows、**Node.js ≥ 18**（i.sh が自動インストール） |
| スマホ / 消費者端末 | モダンブラウザ（Safari, Chrome, Edge）。アプリ不要。 |
| ネットワーク | 送信 HTTPS（443）のみ。受信ポート・ポートフォワーディング不要。 |
| Cloudflare アカウント | フリープランで十分（tunnel + DNS）。制御面がAPI経由でトンネルを自動作成。 |
